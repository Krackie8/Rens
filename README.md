## Khatam Companion

A Quran reader with English translation for every surah and a pace tracker toward a finish date.

Live page: https://krackie8.github.io/Rens/khatam/

- Source files are in [`khatam/`](khatam/). It is one self-contained page with its fonts, so it needs no build step.
- Progress is saved in the reader's own browser. A backup code under "Sharing and backup" moves it between devices.
- Sources and licences: [`khatam/NOTICE.md`](khatam/NOTICE.md).
